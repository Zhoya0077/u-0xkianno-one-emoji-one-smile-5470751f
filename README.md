One emoji, one smile: this entry sends exactly one emoji — 🤗 (hugging face) — the single emoji most likely to make a stranger smile. A smiling face with open arms: warm at first glance, universal across ages and backgrounds, a deliberate pick rather than the default smiley, and friendly without intimacy, sarcasm or flirtation — exactly what the warmth judge's brief rewards.

## Why 🤗

- **Warm on purpose:** a hug plainly aims to warm a stranger, not just to look pleasant.
- **Instant:** smile plus open arms reads kind and gently funny with no context needed.
- **Universal:** a hug means the same thing to a stranger of any age or background — no irony or in-joke.
- **Chosen, not default:** not the first smiley that comes to mind (🙂 / 😊); the open arms make it a deliberate pick while staying instantly readable.
- **Right for a stranger:** a friendly hug carries no intimacy, sarcasm or flirtation.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes exactly one emoji, `🤗`, and nothing else to `$MAKEFUN_OUTPUT_DIR/entry.txt`. It is fully deterministic: every run produces byte-identical output.
